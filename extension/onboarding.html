똑바 (Shop WiseBar)

상품 가격을 자동으로 추적하고, 내려가면 알려드려요.
똑바로 사세요.

1

쇼핑몰 상품 페이지를 방문하세요

네이버+ 스토어 네이버 브랜드 네이버 쇼핑 검색 쿠팡 올리브영
페이지를 보는 순간 가격이 자동으로 기록됩니다. 저장 버튼이 필요 없어요.

상품 페이지 오른쪽 하단에 떠 있는 똑바 버튼
2

화면 오른쪽 하단 25% 지점 똑바 버튼

상품 페이지 오른쪽 하단에 떠 있는 남색 버튼이 바로 똑바입니다.
클릭하면 버튼 주위로 메뉴 5개가 펼쳐지고, 왼쪽에는 가격 추이가 바로 보입니다.

버튼 클릭 시 펼쳐지는 메뉴
3

펼침 메뉴 5가지

오늘의 핫딜 — 1일/7일/30일 할인 상품 모아보기
알림 — 가격 하락·목표가 도달·품절 알림 내역
가격 추이 — 7일(기본)/2주/1달 일별 그래프와 최저·최고가
찜 목록 — 찜한 상품 모아보기, 탭하면 상품 페이지로 이동
설정 — 서버/기기 정보 (확장 설정 페이지)

가격 추이 패널
4

가격이 내려가면 알려드려요

상품 페이지에서 하트를 눌러 상품을 찜하면, 가격이 내려갔을 때 브라우저 알림이 옵니다.
목표가를 설정하면 그 가격에 도달했을 때도 알려드려요.

5

똑바를 툴바에 고정하세요

고정해 두면 퍼즐 메뉴를 열지 않고도 한 번의 클릭으로 현재 상품과 오늘의 핫딜을 볼 수 있습니다.

똑바 팝업 — 현재 상품 정보와 오늘의 핫딜
툴바 상태 확인 중…
서버 주소·기기 ID는 설정 페이지에서 확인할 수 있습니다.
