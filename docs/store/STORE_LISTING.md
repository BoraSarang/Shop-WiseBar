## 상세 설명 (long description)

쇼핑몰 상품의 가격을 보기만 하면 자동으로 추적하고, 같은 상품이라면 쇼핑몰별로 얼마에 파는지 비교해 주는 브라우저 확장 프로그램입니다.

**추적 — 그냥 보기만 하세요**
- 네이버+ 스토어·브랜드, 쿠팡, 올리브영 상품 페이지를 열어 보기만 해도 가격이 자동으로 기록됩니다.
- 저장 버튼이 없습니다. 보통의 쇼핑을 하는 것만으로 가격 이력이 쌓입니다.

**비교 — 같은 상품, 다른 쇼핑몰 가격**
- 보고 있는 상품이 네이버·쿠팡·올리브영에서 각각 얼마인지 한눈에 비교해 드립니다.
- 어느 쇼핑몰이 몇 % 더 저렴한지, 몇 명이 찜하고 있는지도 함께 보여드립니다.

**판단 — 지금이 살 타이밍인지**
- 팝업에서 가격 추이 그래프와 7일/30일/역대 최저가를 확인하세요.
- '역대 최저가 달성', '평균보다 N% 저렴' 같은 구매 타이밍 배지로 판단을 돕습니다.

**알림 — 가격이 내려가거나, 돌아오면**
- 찜한 상품의 가격이 내려가면 브라우저 알림으로 바로 알려드립니다.
- 목표가를 설정하면 그 가격에 도달했을 때 알림을 보내드립니다.
- 품절됐던 찜 상품이 다시 판매되면 알려드립니다. 재입고를 매일 확인할 필요가 없어요.

**전체 핫딜 피드**
- 지금 모든 사용자가 실측한 하락·최저가 상품을 익명 집계로 보여드립니다.

**프라이버시 우선**
- 계정·로그인이 없습니다. 무작위 기기 ID 하나로만 동작해 개인정보를 수집하지 않습니다.

지원 쇼핑몰: 네이버+ 스토어 · 네이버 브랜드 · 네이버 쇼핑 검색 · 쿠팡 · 올리브영 (교차몰 가격 비교 포함)

5. 가격 추이 패널 — 2일 이상 이력 그래프 (shop-wisebar-05.png, 1280×800)

> v0.14.0 권장: 크로스몰 비교(`다른 몰 가격`)와 '재입고' 알림 화면이 담기면 새 기능 반영 스크린샷으로
> 승인 후 교체 가능. 스크린샷 재캡처는 `scripts/store-capture/capture.js`.

> **캡처 방법 (실제 화면 필수 — 심사용)**: Chrome/Edge/Whale에서 확장을 unpacked 로드
> (chrome://extensions → 개발자 모드 → 압축해제된 확장 로드) 후 쇼핑몰 상품 페이지에서
> 팝업을 열고 1280×800 창에서 캡처. 상품 데이터가 비어 있으면 팝업이 빈 화면이므로,
> 미리 상품 페이지를 방문해 가격 이력이 쌓인 상태에서 캡처. 자동화는 `scripts/store-capture/capture.js`.

## 접근 허용 (permissions) 심사 설명

| 권한 | 설명 (스토어에 입력) |
|------|---------------------|
| 사이트 접근(host) | 네이버·쿠팡·올리브영 상품 페이지에서 가격을 읽기 위한 최소 대상 사이트 한정 |
| 알림 표시 | 가격 하락·목표가 도달·품절 복귀 알림 |

| 알림 관리(저장소) | 기기 ID·수집 상태를 기기에 저장 |

## 웨일 스토어 재등록 절차 (v0.14.0 업데이트)

1. https://store.whale.naver.com/developers/upload/draft 접속 (네이버 로그인 — 무료)
2. 기존 **똑바** 확장앱 선택 → 버전 업데이트 → 패키지(ZIP) 업로드: `dist/shop-wisebar-v0.14.0.zip`

4. 권한 심사 설명 확인 (아래 표 그대로 유지)
5. 심사 요청 → 승인 시 웨일 스토어 반영

## 심사 시 유의

- "원격 코드 실행" 없음 — 서버는 가격 저장/조회 API만, 확장 로직은 번들 JS뿐
- 서버 URL은 고정(shop-wisebar.onrender.com) — 사용자 입력 서버 없음, 스크립트 주입 없음
- 개인정보 수집: 익명 device ID + 상품 가격 (제3자 제공 없음)
- 웨일은 크로미움 기반 MV3 호환 — 별도 manifest 수정 불필요 (Chrome Web Store 패키지 그대로 사용)
