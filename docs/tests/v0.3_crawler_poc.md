## 결론 (아키텍처 반영)

1. **서버 크롤러 = 올리브영만** (Playwright, `crawlers/oliveyoung.py`)
2. **네이버/쿠팡 = 익스텐션 전용** (실사용 브라우저 쿠키/컨텍스트로만 통과)
   - 실사용 Chrome 프로필의 osascript 자동화는 통과했으나 v0.3에서 폐기
   - 익스텐션은 브라우저 안에서 실행되므로 동일한 통과 조건 (사용자 방문 시)
3. 사용자가 상품 페이지를 볼수록 서버 데이터 누적 → 멀티 사용자 가정에 부합
