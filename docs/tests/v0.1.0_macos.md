## 테스트 중 발견/수정된 이슈 (P0 픽스)

1. **AX 합성 클릭 무시** — `NSApp.currentEvent`가 nil이면 조기 반환 → 방어 처리 (nil이면 좌클릭 취급). 실제 사용자 클릭엔 영향 없으나 접근성/테스트 호환 확보
2. **DebugPanel 윈도우 크기 축소** — NSHostingController가 콘텐츠 최소 크기(400×272)로 윈도우 축소 → `sizingOptions=[]` + `preferredContentSize` + `setContentSize(600×320)`로 고정
3. **종료 직전 로그 유실** — `push()`가 DispatchQueue.main.async 안에서 print → `NSApp.terminate`가 async 블록 실행 전 종료 → **print를 동기 출력으로 변경**
4. **System Events 메뉴 클릭 타이밍 플레이크** — 메뉴 오픈 직후 즉시 클릭 시 성공, 지연 시 -1719(미등록). 앱 버그 아님, 테스트 툴링 특성으로 기록
