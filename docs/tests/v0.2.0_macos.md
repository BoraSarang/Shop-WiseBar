날짜: 2026-08-02 · 디바이스: macOS 26.5 (arm64, Xcode 26.6, Swift 6.3.3)

P1(가격 추적 MVP) 실상품 통합 테스트. URL 파서/페처 단위 테스트 + 앱 내 실등록/자동 갱신 E2E.

| 입력 | 결과 |
|------|------|

### TC-15 앱 E2E — 올리브영 상품 등록 — PASS

1. 팝오버 열기 (좌클릭) → URL 붙여넣기 → Enter
2. `[ADD] 상품 등록 완료 | mall=oliveyoung, price=39900, productID=A000000171427`
3. 초기 수집: API→ 19:57:40.215 → API← 성공 .918 (**703ms**)
4. 앱 재시작 → 자동 갱신: `total=1, updated=0` (중복 방지 동작), **PERF 366ms**

### TC-16 앱 E2E — 네이버 상품 등록 (수집 대기) — PASS

1. `smartstore...12995638219` 등록 → `[ADD] 초기 수집 실패 — 이름만 등록 (E-MAC-NET-1002)`
2. 저장: `store:notebookland21:12995638219`, 이름 "네이버 상품 (가격 수집 대기)"
3. 자동 갱신: `total=2, failed=1(naver)` — 실패 상품 매 주기 재시도 동작 확인
