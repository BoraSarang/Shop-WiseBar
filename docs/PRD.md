# PRD — Shop WiseBar (똑바)

- **버전**: v0.2.0 · **플랫폼**: macOS (MenuBar) + 중앙 서버 · **작성일**: 2026-08-02 (v0.2 — 서버 아키텍처 전환)
- **원칙**: 네이티브 macOS 개발 (AGENTS.md 네이티브 원칙), 최소 macOS 14 (Sonoma)
- **벤치마크**: 폴센트(Fallcent) — https://fallcent.com (확인 완료: 중앙 서버가 전체 쿠팡 크롤링, 회원가입 없음)

## 1. 개요

**다중 사용자 서비스형 가격 추적 메뉴바 앱.** "가격이 떨어지면 메뉴바가 알려준다."

- Fallcent의 코어 기능(중앙 상품 DB + 가격 변동 추적 + 알림 + 가격 통계)을 Mac 메뉴바 앱 + 중앙 서버로 제공
- 모든 사용자에게 공통된 **중앙 상품 DB**가 존재 — 어떤 사용자가 등록하지 않아도 상품 정보/가격 이력은 서버에 축적
- 확장 프로그램 없이 동작

## 2. 아키텍처 (v0.2 변경 — 핵심)

```
[macOS 클라이언트 (메뉴바 앱)]                [중앙 서버 (FastAPI + DB)]
  ├─ BrowserMonitor (탭 URL 폴링)  ──등록/조회──▶  ├─ 상품 마스터 DB (몰/상품ID/이름/이미지)
  ├─ 클립보드 감지 (P3)                          ├─ 가격 이력 DB (PricePoint: 상품ID/가격/시각)
  ├─ 브라우저 세션 가격 추출  ──업로드──▶         ├─ 사용자 DB (익명 기기ID + 관심 상품 목록)
  ├─ 폴링 알림 (수 분 주기 조회) ──조회──▶       └─ 크롤러 워커 (갱신 오래된 상품 자동 수집)
  └─ 메뉴바 UI (카드/그래프/자동 팝오버)
```

- **클라이언트**: 브라우저 캐치, 가격 추출(브라우저 세션), 메뉴바 UI, 로컬 알림
- **서버**: 상품/가격 이력/사용자 데이터 중앙 관리, 자동 크롤링, 관심 상품 상태 판별
- **수집**: 하이브리드 — ①클라이언트가 브라우저 세션으로 수집해 서버에 업로드 ②서버 크롤러가 갱신이 오래된 상품 자동 수집 (네이버/쿠팡은 서버 IP 차단 실측 — 서버 단독 크롤링 불가)

## 3. 핵심 사용자 흐름 (최종 목표)

1. 사용자가 브라우저로 쇼핑몰 탐색 → **상품 정보 페이지 캐치** (3초 폴링)
2. 캐치한 상품을 **서버 상품 DB에서 조회** → 없으면 등록, 있으면 최신 정보 확인
3. **내 관심 상품이면 메뉴바 팝오버 자동 표시** — 가격 추이 그래프 + 기본 정보 (목표가/최저가/변동률)
4. 가격이 하락하거나 목표가 도달 → 서버가 감지 → 클라이언트 폴링 → 로컬 알림 → 알림 클릭 시 해당 상품 정보 메뉴바 표시

## 4. 핵심 기능

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 브라우저 상품 캐치 | 활성 탭 URL 폴링 → 몰 판별 → 서버 조회 | 1 |
| 관심 상품 자동 팝오버 | 캐치 상품이 관심 목록에 있으면 메뉴바 자동 오픈 + 가격 추이 표시 | 1 |
| 가격 변동 알림 | 하락/목표가 도달 시 클라이언트 폴링 → 로컬 알림 → 클릭 시 상품 표시 | 1 |
| 중앙 상품 DB | 상품 마스터 + 가격 이력 서버 축적 (전 사용자 공유) | 1 |
| 자동 크롤링 | 서버 크롤러가 갱신 오래된 상품 자동 수집 (하이브리드 보완) | 1 |
| 클라이언트 수집 업로드 | 브라우저 세션 가격 추출 결과 서버 업로드 | 1 |
| 가격 통계/그래프 | 최저/최고/평균/변동률 + Swift Charts | 2 |
| 클립보드 감지 | 공유 URL 복사 시 인식 (P3) | 3 |
| 익명 기기 ID | 최초 실행 시 발급, 관심 상품 서버 동기화 (회원가입 불필요) | 1 |

## 5. 상품 감지 방식 (우선순위)

1. **브라우저 감시 (P2)** — 설정에서 브라우저 지정(크롬 계열/웨일) → 상품 페이지 접속 감지 → 몰 판별(쿠팡/네이버/올리브영) → 서버 조회
2. **클립보드 감지 (P3)** — 공유하기 주소 복사 시 인식 (비상품 페이지일 때만)
3. **브라우저 익스텐션 (P4)** — 2단계로 포함 여부 검토

## 6. 지원 몰 (MVP: 3개)

| 몰 | 수집 방식 | 비고 |
|----|-----------|------|
| 쿠팡 | 브라우저 세션 (Chrome `execute javascript`) | Akamai 우회, 회원 할인가 반영 |
| 네이버 (스마트스토어/쇼핑) | 브라우저 세션 (m. 모바일 페이지) | HTTP IP 차단(429) 실측 |
| 올리브영 | HTTP + HTML 파싱 | |

확장 몰(무신사/11번가/컬리)은 P4에서 추가.

## 7. 메뉴바 UX

- **좌클릭**: 팝오버 — 추적 상품 카드(이미지/현재가/변동/그래프), 상품 감지 시 "추적할까요?" 제안 배너
- **자동 표시**: 관심 상품 페이지 캐치 시 / 알림 클릭 시 팝오버 자동 오픈
- **우클릭**: 찜한 상품 관리 / 지금 상품 추가 / 설정 / Debug Panel(Cmd+D) / 정보 / 종료

## 8. 비기능 요구사항

- 성능 예산: Cold Start ≤ 1.5s, 메모리(debug) ≤ 300MB, 60fps
- 에러: `E-MAC-{CAT}-NNNN` / `E-SRV-{CAT}-NNNN` 체계 + 사용자 메시지 `error_message_ko.json` 분리
- 보안: 시크릿 하드코딩 금지, DebugPanel은 `#if DEBUG` 컴파일 타임 제거, API 토큰은 Keychain 저장
- 권한: 브라우저 자동화(TCC) 1회 승인 — `NSAppleEventsUsageDescription` 명시

## 9. 범위 제외 (현재)

- 모바일 앱, 웹 앱 (메뉴바 앱이 1차 플랫폼)
- 크로스플랫폼 프레임워크 사용 금지 (네이티브 원칙)
- 계정/결제 시스템 (익명 기기 ID만)
