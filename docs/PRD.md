# 똑바(Shop WiseBar) PRD — v0.3.0 (중앙 서버 + 브라우저 익스텐션)

> 2026-08-03 재구성: 맥 메뉴바 앱 폐기 → 중앙 서버 + 브라우저 익스텐션 구조로 전면 재설계

## 1. 제품 개요

- **제품명**: 똑바 (Shop WiseBar)
- **핵심 가치**: 쇼핑몰 상품의 가격을 자동 추적하여 "지금 사도 되는 가격"을 알려준다.
- **아키텍처**: 중앙 서버(상품 DB + 가격 이력 + 알림 계산) + 브라우저 익스텐션(수집 + 찜 관리 + 알림 수신)
- **멀티 사용자 가정**: 여러 사용자가 같은 서버를 사용, 상품/가격 데이터는 전 사용자 공유 (계정 없이 익명 기기ID)

## 2. 수집 우선순위 (확정)

| 순위 | 채널 | 커버 몰 | 방식 |
|------|------|---------|------|
| 1 | 중앙 서버 크롤러 | 올리브영 (실측 성공) | Playwright headless 주기 수집 |
| 2 | 브라우저 익스텐션 | 네이버/쿠팡/올리브영 전부 | 사용자가 상품 페이지를 볼 때 DOM에서 추출 → 업로드 |
| 3 | (폐기) 맥 메뉴바 osascript | — | 2026-08-03 제거됨 |

- 네이버/쿠팡은 서버(쿠키 없는 브라우저) 자동 수집이 실측으로 불가(캡차/Akamai 차단).
  익스텐션이 유일한 자동 수집 채널이며, 여러 사용자가 페이지를 방문할수록 서버 데이터가 누적된다.
- 추후 공식 API(네이버쇼핑, 쿠팡 파트너스) 검토는 옵션 C로 계속 열어 둠.

## 3. 사용자 스토리

1. 사용자가 크롬에서 네이버+ 스토어/쿠팡/올리브영 상품 페이지를 열면 → 익스텐션이 가격/제목/이미지를 추출해 서버로 업로드 (수동 조작 없음)
2. 익스텐션 팝업에서 상품을 "찜"하고 목표가를 설정
3. 서버가 주기적으로(방문 수집 + 올리브영 크롤러) 가격을 갱신
4. 가격이 하락했거나 목표가에 도달하면 → 브라우저 알림으로 통지
5. 팝업에서 찜 목록, 가격 추이 그래프, 최근 알림을 확인

## 4. 핵심 기능

### 4.1 자동 수집 (익스텐션)
- `chrome.tabs.onUpdated`로 상품 페이지 URL 감지 → content script로 DOM 가격 추출 → 서버 업로드
- 같은 상품 재방문 시에도 최신 가격 반영 (서버 price_points에 이력 추가)

### 4.2 서버 크롤러 (1순위)
- 올리브영: Playwright headless 주기 크롤링 (실측: 가격 39,900원 + og:title/og:image 수집 성공)
- 네이버/쿠팡: 자동 불가 (실측 기록: docs/tests/v0.3_crawler_poc.md)

### 4.3 찜 + 목표가
- 팝업에서 찜 추가/해제, 목표가 설정 (서버 watches API, 기기ID 기준)

### 4.4 가격 변동 알림
- 서버 alerts API 폴링(chrome.alarms) → `chrome.notifications` 브라우저 알림
- 하락 감지(직전 가격 대비) + 목표가 도달 두 종류

### 4.5 가격 추이
- 팝업에서 상품 클릭 → 가격 이력 그래프(캔버스/SVG, 서버 prices API)

## 5. 지원 몰 & URL 패턴 (productID 규약)

| 몰 | URL 패턴 | productID |
|----|----------|-----------|
| 네이버+ 스토어 | `shopping.naver.com/{store}/products/{id}` | `store:{store}:{id}` |
| 네이버 브랜드 | `brand.naver.com/{store}/products/{id}` | `brand:{store}:{id}` |
| 네이버 쇼핑 카탈로그 | `search.shopping.naver.com/catalog/{id}` | `c:{id}` |
| 쿠팡 | `coupang.com/vp/products/{id}` | `{id}` (몰=쿠팡) |
| 올리브영 | `oliveyoung.co.kr/...?goodsNo={no}` | `{no}` (몰=올리브영) |

## 6. 비기능 요구사항

- **프라이버시**: 기기ID는 익명 UUID, 계정/개인정보 없음. 상품 데이터는 공유지만 찜/알림은 기기별 격리
- **브라우저 호환**: Chrome MV3 기준 (Edge/Whale은 manifest 그대로 로드 가능)
- **오프라인**: 서버 다운 시 수집 보류(재시도 큐), 로컬 찜 상태는 chrome.storage에 캐시
- **성능 예산**: 콘텐츠 스크립트는 100ms 이내 추출, 탭 이벤트 시 불필요한 요청 금지(URL 변경 시에만)
- **비용**: 서버는 무료 계층(FastAPI + SQLite) 기준, 크롤러는 1일 1회 수준으로 억제
