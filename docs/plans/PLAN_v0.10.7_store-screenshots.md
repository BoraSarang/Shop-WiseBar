# PLAN v0.10.7 — 웨일 스토어 심사용 스크린샷 재구성 (플로팅 화면 추가)

- 플랫폼: chrome(웨일) + server
- 날짜: 2026-08-06
- 상태: 진행 중

## 개요

기존 `shop-wisebar-01/02.png`는 둘 다 **팝업(320×600) 화면만** 담아 실제로 동일한 화면이었다
(7일 탭이 기본 active라 화면 차이가 없음). 또한 **플로팅 버튼(FAB)** 이 보이는 실사용 화면이
없어 스토어 심사(1280×800 이상 요구)에 부적합했다.

이번 버전에서 `capture.js`를 수정해 **상품 페이지(1280×800) + 플로팅 버튼 화면**을 추가하고,
팝업 화면은 별도 번호로 분리한다.

## 결정 사항

1. 스크린샷 구성 (3장):
   - `shop-wisebar-01.png` — **상품 페이지 전체(1280×800)** — 플로팅 버튼이 보이는 실사용 화면
   - `shop-wisebar-02.png` — 팝업(320×600) — 현재 상품 탭
   - `shop-wisebar-03.png` — 팝업(320×600) — 핫딜 7일 탭
2. 데모 데이터는 유지(핫딜 5개 + 현재 상품 가격 이력 3개). 하락 시점이 "지금"이라 1일/7일/30일
   탭 목록이 동일하므로, 팝업 2장의 구분은 "7일 탭 클릭 전/후"가 아닌 다른 방식으로 한다.
3. 팝업 02/03 구분: `capture.js`가 7일 버튼을 클릭하지 않고, 02는 "기본 상태(로딩 완료 직후)",
   03은 "7일 버튼을 명시 클릭 후"로 구분한다. (사실상 동일하지만 01이 크게 달라지므로
   심사용으로는 3장 모두 제출 가능한 구성)
4. (고려) 기간별 다른 목록이 꼭 필요하면 prices POST에 `captured_at` 확장 — 이번엔 범위 제외.
