# PLAN v0.12.0 — 가격 추이 그래프 전면 재설계 (extension)

> 버전: v0.12.0 / 플랫폼: chrome(확장) / 상태: ✅ 완료 / 작성: 2026-08-06
> 관련: docs/TODO.md T-100, docs/CHANGELOG.md v0.12.0

## 1. 개요

플로팅 패널 가격 추이 그래프(`extension/swb-ui.js` `drawChart`)의 3가지 문제를 사용자가 지적:

1. **2일치 데이터인데 그래프가 7일로 늘어나 보임** — `dailySeries`가 결측일을 직전 가격으로 보간(961행)해
   기록 2일이어도 X축 인덱스(7일) 전체에 포인트가 찍힘. X축 날짜 라벨도 없음.
2. **최대값이 꼭대기에 딱 붙음 / 하단에 점** — Y축이 데이터 min/max를 캔버스 세로 100%(pad 8px)로 사용.
   가격 변동 없는 상품(min==max)은 `range = max-min || 1`에 의해 모든 포인트가 하단 pad에 납작한 선으로 그려지고,
   최저/최고 마커 2개가 같은 좌표에 겹쳐 "하단의 점"으로 보임.
3. **가격 변동 없는 상품이 납작** — min==max 처리 부재.

전면 재설계로 실제 날짜 스케일 X축 + Y축 여유(버퍼) + 그리드/평균선/최저선 + min==max 중앙 배치 + DPR 선명도를 적용한다.

## 2. 결정 사항

1. **데이터**: `dailySeries`가 결측 보간을 버리고 **실제 기록일만** `{t(ms), price}[]`로 반환
   (오늘은 페이지 현재 가격 nowPriceCache로 병합, 중복 시 오늘 우선). `days`(7/30) 범위 밖 날짜 제외.
2. **X축**: 기록일 min~max **실제 시간 범위**를 캔버스 가로에 매핑(앞뒤 pad). 기록 2일이면 좌우로 퍼져 "2칸"처럼 보임.
   기록 1일이면 중앙 단일 점. 하단에 첫/마지막 기록일 `M/D` 날짜 라벨.
3. **Y축**: 데이터 range의 **10% 상하 버퍼** + 상하 pad(상 18 / 하 20px). 최소값이 0보다 작아지지 않게 clamp.
   → 최대값이 꼭대기에 안 붙고(세로 ~90%만 사용), 사용자 요구 "최대값보다 조금 더 크게" 충족.
4. **min==max**: 하단 납작 대신 **캔버스 중앙 단일 점 + "변동 없음"** 표시.
5. **레이어**: 수평 그리드 3줄(min/mid/max, 점선) + **평균선**(회색 점선) + **최저선**(파란 점선 + "최저 N원" 라벨) 유지.
   하락 구간 파란 굵은 선 / 상승·평탄 회색 얇은 선 유지. 데이터 포인트마다 작은 점.
   최저/최고 마커는 같은 좌표면 회색 1점으로 대체(겹침 방지).
6. **DPR**: `devicePixelRatio` 반영으로 고해상도 선명도 개선. CSS 크기 292×140 유지, backing store만 스케일.
7. **가격 라벨**: 우상단 마지막 가격(기존 유지) + 하단 양쪽 날짜 라벨. 좌하단 첫 가격 라벨은 최저 라벨과 중복되므로 제거.
8. **통계(렌더 상단)**: delta는 첫 기록일 가격 vs 오늘, st-min/st-max는 기록일 가격 min/max, st-count는 기록일 수 — 기존 로직 유지.

## 3. 아키텍처

```
extension/swb-ui.js
├── dailySeries(points, days, nowPrice)  # 수정 — 결측 보간 제거, {t, price}[] 반환
├── drawChart(canvas, points, rangeDays) # 전면 재작성 — DPR + 날짜 X축 + 버퍼 Y축 + 그리드/평균/최저선 + min==max
└── renderTrend(serverError)             # 호출부만 {series,recordDays} → {points,recordDays}로 대응
```

- 서버 API·스키마·팝업·기타 UI 변경 없음. `pointsCache`(price_points) 소스 불변.
