# 똑바(Shop WiseBar) 확장 E2E 자동화

로컬 서버 격리 + 실제 Whale 브라우저 + 실제 확장으로 전체 파이프라인
(가격 추출 → 서버 저장 → 팝업 표시)을 자동 검증하는 E2E.

## 실행

```bash
./scripts/e2e/run-e2e.sh                # 기본 상품 (올리브영)
./scripts/e2e/run-e2e.sh [상품URL]      # 특정 상품 지정
```

- 포트: 기본 8765 (8000은 타 프로젝트 점유 가능). 변경 시 `SWB_E2E_PORT=9000 ./scripts/e2e/run-e2e.sh`
- 첫 실행 전 의존성: `cd scripts/e2e && npm install`

## 동작 순서

1. **서버 기동**: 로컬 uvicorn + 임시 SQLite DB (운영 DB 오염 없음, 종료 시 자동 삭제)
2. **데모 데이터 주입**: 핫딜 5개 (가격 하락 이력) — 팝업 핫딜 탭 채우기
3. **확장 복사본 생성**: `common.js`의 서버 주소를 로컬 포트로 치환 (실제 `extension/` 원본 불변)
4. **Whale + 확장 로드**: 기존 `.whale-profile` 복사본 재사용 (네이버 봇 감지 우회)
5. **상품 페이지 방문**: 콘텐츠 스크립트가 가격 추출 → background가 서버 업로드
6. **팝업 열기**: 현재 상품/가격/통계/핫딜 렌더링 검증
7. **정리**: 데모 데이터 삭제 (404 확인) + 브라우저/복사본/프로필 임시 파일 제거

## 검증 시나리오

| TC | 검증 내용 |
|----|-----------|
| TC-E2E-001 | 서버 /health ok + 확장 로드 (ID 확인) |
| TC-E2E-002 | 상품 페이지 가격 추출 → 서버 저장 |
| TC-E2E-003 | 가격 이력 존재 (price_points ≥ 1) |
| TC-E2E-004 | 팝업 상품명/현재가/통계 표시 |
| TC-E2E-005 | 핫딜 5개 표시 + 빈 상태 숨김 |
| TC-E2E-006 | 데모 정리 (404 확인) |

## 몰별 주의사항

| 몰 | 상태 |
|----|------|
| 올리브영 | ✅ 기본 사용 — 봇 차단 없음, 안정적 |
| 네이버+ 스토어 | ⚠️ 자동화 브라우저 접속 시 **HTTP 429 봇 차단** 가능. 차단 시 상품 페이지가 에러 페이지로 리다이렉트되어 추출 실패. 일정 시간(수십 분~몇 시간) 후 재시도 필요 |
| 쿠팡 | ⚠️ 403/봇 차단 이슈 (기존 확인 사항) |

네이버/쿠팡으로 검증할 때 429/403이 나면 올리브영 상품 URL로 대체해서 실행하면 됩니다.

## 실패 시

- 실패해도 데모 데이터는 무조건 정리됩니다 (JS try/finally + shell trap)
- 남은 데모 수동 정리: `node scripts/store-capture/cleanup.js`
- 로그: 서버는 `--no-access-log` (조용히), 확장 디버그는 팝업 Debug 탭에서 확인
